Watch without a task to finish.

In Muse, the controls clear away after motion begins. You can watch the cube open, flatten, and form new arrangements in projection.

Try a slower speed and follow a corner. Try vertices alone to see the cloud of points. Restore edges to recover the connections between them.

The original hypercube stays rigid. The changing image comes from the way its rotation meets the projection.

A question to sit with

Can you recognize the same arrangement when it returns? Is it the same orientation in the full space, or only a similar-looking projection?

Watch the path as well as the point.

Enable Trace vertex in the appearance controls to highlight a single corner and dim the rest. Its recent path remains visible for the selected duration, from 1–60 seconds. Pause holds the pattern for closer inspection; Resume continues it. Restart trace clears the history at the current position.

The browser illustration below lets you explore the same ideas. Its presets are controlled examples; Muse in the Android app chooses a random rotation.

Enable JavaScript for the browser illustration. Use Pause to hold the trail in place.

Gold is the recent path of the white vertex. The trail keeps recording through crossings. Reduced-motion preferences start this illustration paused.
